# Documentación transversal

Esta carpeta contiene mapas, reportes y decisiones generales del proyecto.

- [PROJECT_MAP.md](./PROJECT_MAP.md): estado y estructura comprobados del repositorio.
- [implementation-report-legacy.md](./implementation-report-legacy.md): plan/reporte generado antes de adoptar la estructura `spec.md → plan.md → tasks.md`; se conserva solo como historial.

Los documentos ejecutables de una funcionalidad viven en `specs/<número>-<nombre>/` y se leen en orden:
`spec.md → plan.md → tasks.md`.
